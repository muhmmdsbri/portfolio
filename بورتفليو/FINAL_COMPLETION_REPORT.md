## 🎨 COLOR REFERENCE

### Dark Theme Colors
```
Background:     #0A0E27 (Dark Black)
Text:           #FFFFFF (White)
Accents:        #FFD700 (Gold)
Secondary:      #B0B8C8 (Light Gray)
Borders:        rgba(255,255,255,0.1) (Subtle White)
```

### CSS Variables
```css
--primary: #FFFFFF          /* White text */
--accent: #FFD700           /* Gold accents */
--dark: #0A0E27             /* Dark background */
--text-light: #B0B8C8       /* Light gray text */
```

## 🔧 CUSTOMIZATION QUICK TIPS

### Change Accent Color
- Find: `--accent: #FFD700;` in style.css
- Replace with your color
- Popular: #0066FF (blue), #9D4EDD (purple), #10B981 (green)

### Adjust Hero Overlay
- Find: `rgba(10, 14, 39, 0.7)` in hero background
- Change 0.7 to 0.5-0.9
- 0.5 = lighter, 0.8 = darker

### Change Background
- Find: `--dark: #0A0E27;` in style.css
- Replace with your color
- Darker: #000000, #0F0F1E, #1A1A2E
