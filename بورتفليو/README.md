## 🚀 كيفية الاستخدام

### 1. فتح الموقع
ببساطة افتح ملف `index.html` في متصفحك المفضل:
```bash
# Windows
start index.html

# Mac
open index.html

# Linux
xdg-open index.html
```

### 2. تخصيص البيانات
عدّل ملف `data/portfolio-data.json` لتحديث:
- **البيانات الشخصية** (الاسم، البريد، الهاتف، إلخ)
- **المهارات** (أضف/احذف/عدّل المهارات)
- **المشاريع** (أضف مشاريعك الخاصة)
- **الأسعار** (حدّث أسعار خدماتك)
- **الشهادات** (أضف شهاداتك وتعليمك)

### 3. تحديث الصورة الشخصية
استبدل ملف `assets/images/profile.svg` بصورتك الخاصة:
- الحجم الموصى به: 400x400 بكسل
- الصيغ المدعومة: JPG, PNG, SVG, WebP

  font-family: 'YOUR_FONT', sans-serif;
