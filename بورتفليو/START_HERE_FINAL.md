## 🐛 Troubleshooting

### Skills Not Showing?
- Check browser console (F12)
- Verify JSON syntax
- Refresh browser (Ctrl+F5)
- See `SKILLS_CERTIFICATES_GUIDE.md`

### Content Not Updating?
- Save JSON file
- Hard refresh browser (Ctrl+F5)
- Check for JSON errors
- See `QUICK_EDIT_REFERENCE.md`

### Language Toggle Not Working?
- Verify Arabic text is filled in
- Check field names (e.g., `titleAr`)
- Refresh browser
- See `SKILLS_CERTIFICATES_GUIDE.md`
